Project Description

Ini adalah website yang menyediakan jadwal klinik, pemantauan warga sekitar, serta penjelasan mengenai berbagai penyakit. Selain itu, terdapat peran admin yang dapat menambahkan atau mengubah data jadwal, pemantauan, dan informasi lainnya. Website ini dibuat menggunakan Laravel, terhubung dengan database, dan didukung oleh Bootstrap untuk tampilan antarmuka yang responsif dan modern.

Contributions
  • Merancang desain antarmuka website menggunakan Canva dan Bootstrap.
  • Mengembangkan bagian frontend untuk menampilkan jadwal klinik, pemantauan warga, dan informasi penyakit.
  • Membangun backend menggunakan Laravel untuk mengelola data dan peran admin.
